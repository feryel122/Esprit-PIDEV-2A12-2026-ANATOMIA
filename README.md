


# ANATOMIA – Plateforme de santé et de bien-être inclusif

## Description

ANATOMIA est une plateforme web dédiée à la santé et au bien-être inclusif. Elle a pour objectif de faciliter l'accès aux informations anatomiques et aux services de santé.

Le projet répond au problème de la dispersion des informations et des services liés à la santé en les regroupant dans une seule plateforme.

Ses principales fonctionnalités sont :
- Consultation des informations sur l'anatomie humaine.
- Découverte de recettes saines et de tisanes.
- Gestion des utilisateurs et des profils.
- Recherche de médecins et gestion des rendez-vous.
- Participation à un forum communautaire.
- Consultation d'articles sur la santé.
- Localisation des pharmacies et des restaurants proposant des repas sains grâce à une carte interactive.

## Installation

1. Clonez le repository :

```bash
git clone https://github.com/feryel122/Esprit-PIDEV-2A12-2026-ANATOMIA.git
cd Esprit-PIDEV-2A12-2026-ANATOMIA
```



2. Si vous utilisez WAMP ou XAMPP :

   - Placez le dossier ANATOMIA dans le dossier `www` (WAMP) ou `htdocs` (XAMPP).
   - Démarrez Apache et MySQL depuis l'interface de WAMP/XAMPP.
   - Accédez au projet via :

```text
http://localhost/ANATOMIA
```

3. Configurez la base de données MySQL :

   - Ouvrez phpMyAdmin.
   - Créez une base de données pour ANATOMIA.
   - Importez le fichier SQL du projet si disponible.
   - Configurez la connexion à la base de données.

## Utilisation

### Installation de PHP

Pour utiliser ANATOMIA, vous devez disposer de PHP et d'un serveur local comme WAMP ou XAMPP.

1. Téléchargez et installez [XAMPP](https://www.apachefriends.org/fr/index.html) ou [WampServer](https://www.wampserver.com/).

2. Démarrez les services Apache et MySQL.

3. Vérifiez l'installation de PHP en exécutant la commande suivante dans le terminal :

```bash
php -v
```

4. Ouvrez votre navigateur et accédez à l'application :

```text
http://localhost/ANATOMIA
```

5. Accédez à phpMyAdmin pour gérer la base de données MySQL :

```text
http://localhost/phpmyadmin
```
