# ANATOMIA

**Team:** Brainwave  
**Class:** 2A12  
**Project Theme:** Inclusive Health and Well-being

## Project Description
ANATOMIA is a web platform focused on health and well-being. It provides anatomical information, healthy recipes, medical appointment management, health articles, and interactive services.

## Main Modules
- Human Body
- Recipes
- Users
- Free Forum & Community Hosting
- Health Articles
- Healthy Map & Services
- Medical Appointments

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Architecture
The project follows the MVC (Model-View-Controller) architecture.
